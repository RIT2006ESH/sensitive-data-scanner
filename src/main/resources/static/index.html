Detection Rules

Card Number

13–19 digit sequences, either unbroken or grouped in uniform blocks of 4 (e.g. 4111 1111 1111 1111).

Validation: Luhn checksum.

Aadhaar Number

12 digits, grouped in blocks of 4. First digit restricted to 2–9 per UIDAI format (never starts with 0 or 1).

Validation: Verhoeff checksum.

PAN Number

Format AAAA A 9999 A. 4th letter restricted to real holder-type codes (A, B, C, F, G, H, J, L, P, T).

Validation: Structural format only.
